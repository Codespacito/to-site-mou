# Το site μου

Ιστοσελίδα φτιαγμένη με το [Hugo](https://gohugo.io), που είναι ανοιχτού κώδικα, για ποιήματα, στίχους, κείμενα και φωτογραφίες.

## Πού βρίσκονται τα πράγματα

| Φάκελος | Τι περιέχει |
|---|---|
| `content/poiimata/` | Ποιήματα |
| `content/stixoi/` | Στίχοι |
| `content/keimena/` | Κείμενα |
| `content/fotografies/` | Φωτογραφίες (ένας φάκελος για κάθε φωτογραφία) |
| `hugo.toml` | Ρυθμίσεις: τίτλος site, όνομα, μενού |
| `layouts/` | Η εμφάνιση του site (δεν χρειάζεται να το πειράξεις) |

## Νέο ποίημα, στίχοι ή κείμενο

Φτιάξε ένα νέο αρχείο `.md` μέσα στον σωστό φάκελο, π.χ. `content/poiimata/to-onoma-mou.md`, με λατινικούς χαρακτήρες και παύλες αντί για κενά στο όνομα:

```
---
title: "Ο τίτλος του ποιήματος"
date: 2026-11-20
---

Πρώτος στίχος
δεύτερος στίχος

Νέα στροφή μετά από κενή γραμμή
```

## Νέα φωτογραφία

Φτιάξε έναν φάκελο μέσα στο `content/fotografies/`, π.χ. `content/fotografies/thalassa/`, και βάλε μέσα:
- τη φωτογραφία (`.jpg` ή `.png`)
- ένα αρχείο `index.md` με τίτλο και ημερομηνία, όπως στο παραπάνω παράδειγμα

Το site φτιάχνει μόνο του τις μικρογραφίες.
